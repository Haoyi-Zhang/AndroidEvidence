# Paper source

This directory contains the single-column ACM review source, bibliography, generated count fragments, and embedded-font vector figures. The review uses the ACM template's `manuscript,screen,review` mode. Fonts, margins, and page dimensions come from the unmodified class.

## Build from the complete project

First reproduce the sibling artifact so manuscript-facing count fragments are current:

```bash
cd ../artifact
PYTHONDONTWRITEBYTECODE=1 python scripts/reproduce.py --out /path/to/check-output
cd ../paper
PYTHONDONTWRITEBYTECODE=1 python build.py --results /path/to/check-output
```

Keep that output directory outside the artifact to preserve historical raw results.
On Windows, set `PYTHONUTF8=1` and `PYTHONDONTWRITEBYTECODE=1` in the invoking
shell and use `python -B`. Without `--results`, the build imports the retained
`artifact/results/tex/` fragments; that default does not establish their freshness.

The build requires `pdflatex`, `bibtex` or `bibtex8`, `pdfinfo`, and Matplotlib for the three conceptual diagrams. The artifact's `figures/build_figures.py` draws these directly without TeX. The build:

- audits all citations and requires at least 55 unique cited works;
- requires byte-identical paper and artifact bibliography snapshots;
- imports deterministic TeX fragments generated by the artifact and regenerates the three vector figures;
- requires `\documentclass[manuscript,screen,review]{acmart}`;
- rejects `nonacm`, manual geometry/font overrides, and negative vertical spacing; unassigned DOI/reference/copyright furniture is omitted;
- compiles without shell escape;
- fails on overfull boxes, undefined citations/references, undefined control sequences, or a review copy exceeding the local 39-page budget;
- writes only `build/main.pdf` as the PDF output, plus `build-evidence.json`, `bibliography-audit.json`, and `bibliography-warnings.txt`;
- binds the output PDF and final log to active TeX inputs, included vector figures, bibliography and publisher template. Delivery gates reject a stale PDF even if it fits the page budget.

The current manuscript has 39 pages including references. The local 39-page budget is a project constraint, not a verified CSUR submission cap. The driver reports the actual count without adding filler. POSIX child CPU/RSS diagnostics are reported where the operating system provides them.

`build-evidence.json` records the owned five-command compiler run, final engine log, active sources and output bindings. Unavailable Windows child CPU/RSS measurements remain null. `visual-inspection.json` records all 39 viewed pages at 104.4 dpi, individual diagrams at 180 dpi, and exact pixel/link identity between the registered and owned-driver builds. Every listed font is embedded and none is Type 3. The artifact's `manuscript_snapshot/` is a byte-identical delivery mirror for artifact-only use. Each tree has one `build/main.pdf`; the primary source remains `paper/`. Layout inspection is not independent peer review or source-interpretation certification. Rebuild and reinspect after later changes.
