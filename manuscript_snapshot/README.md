# Paper source

This directory contains the internal 35-page ACM `acmsmall` survey source, bibliography, generated count fragments, native TikZ figures embedded in the section files, and compiled PDF.

## Build from the complete project

First reproduce the sibling artifact so manuscript-facing count fragments are current:

```bash
cd ../artifact
PYTHONDONTWRITEBYTECODE=1 python scripts/reproduce.py
cd ../paper
PYTHONDONTWRITEBYTECODE=1 python build.py
```

The build requires `pdflatex`, `bibtex` or `bibtex8`, and `pdfinfo`. It:

- audits all citations and requires at least 55 unique cited works;
- requires byte-identical paper and artifact bibliography snapshots;
- imports deterministic TeX fragments generated by the artifact;
- requires `\documentclass[acmsmall,screen,review]{acmart}`;
- rejects `nonacm`, top-matter suppression, manual geometry/font overrides, and negative vertical spacing;
- compiles without shell escape;
- fails on overfull boxes, undefined citations/references, undefined control sequences, or any page count other than 35;
- writes `paper.pdf`, `build-evidence.json`, `bibliography-audit.json`, and `bibliography-warnings.txt`.

## Current checked result

- 35 pages including references;
- 97 bibliography entries, all cited;
- 259 citation occurrences;
- nine main sections, 57 subsections, ten tables, and three native TikZ figures;
- zero BibTeX warnings and zero fatal LaTeX findings;
- all 35 pages inspected at 180 DPI, with the result recorded in `visual-inspection.json`.

The manuscript is an internal research draft. It contains no invented repository URL and is not an external submission or acceptance claim.
